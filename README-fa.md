# tcmb-mcp 🇹🇷

سرور MCP غیررسمی و **فقط‌خواندنی** برای نرخ‌های ارز بانک مرکزی ترکیه (TCMB) — نرخ زنده‌ی لیر برای ۲۲ ارز + تاریخچه.

> پایلوت «کارخانه‌ی MCP ترکیه» (پایپ‌لاین به سبک سپهر). هیچ وابستگی به TCMB ندارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "tcmb": {
      "command": "uvx",
      "args": ["tcmb-mcp==0.1.2"]
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `tcmb_get_rates` | نرخ‌های امروز هر ۲۲ ارز (لیر) |
| `tcmb_get_rate` | یک ارز خاص — `code`: ‏USD، ‏EUR، ‏GBP… |
| `tcmb_list_currencies` | همه‌ی کدهای ارز بولتن امروز |
| `tcmb_get_rates_on` | نرخ تاریخی — `date`: به قالب YYYY-MM-DD (فقط روزهای کاری) |

## قوانین

غیررسمی و فقط‌خواندنی — بدون لاگین، بدون کلید، بدون نوشتن. تست‌ها: آفلاین با فیکسچر + تست زنده (۱۴/۱۴ سبز).
